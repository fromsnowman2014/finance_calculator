# Finance Calculator

A web application for visualizing compound interest growth over time

## Features

- Compound interest calculation and simulation
- Yearly asset growth trend charts
- Regular contribution impact analysis
- Dark mode support
- Responsive design

## Tech Stack

- **Framework**: Next.js 16 (React 19)
- **Styling**: Tailwind CSS 4
- **Charts**: Recharts
- **State**: Zustand
- **Animation**: Framer Motion
- **Language**: TypeScript

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
npm start
```

Development server: [http://localhost:3000](http://localhost:3000)
